#☕ Logic and Object-Oriented Programming with Java
This repository marks the first 15 days of my immersion into Java, consolidating the core concepts of programming logic, data structures, and the pillars of Object-Oriented Programming (OOP).
The goal of this project was to master business logic, collections, and pure language syntax, building a rock-solid foundation before moving on to high-level frameworks.
🚀 What was developed?
During this initial two-week sprint, the focus was divided into practical modules designed to master Java Core:
Logic and Java Syntax: Handling primitive types, conditional structures (if/else, switch-case), loops (while, for), and basic exception handling.
The Pillars of OOP: Practical implementation of fundamental concepts in real-world scenarios:
Abstraction and Encapsulation: Creating classes, private attributes, accessor methods (getters/setters), and custom constructors.
Inheritance and Polymorphism: Method overloading and overriding to build reusable, flexible code.
Java Collections Framework: Dynamic memory and data management using structures like List (ArrayList) and handling data streams.
Date and Time API: Practical use of modern Java time classes (such as LocalDateTime) for controlling and manipulating time-stamped records.
🛠️ Technologies and Tools
Language: Java (Version 21)
IDE: IntelliJ IDEA
